# 台北101煙火視野探索 V2

這是可執行的研究原型，參考日本煙火視野地圖的「地圖選點→地面視角」互動概念；沒有複製該網站程式碼或資料。

## Windows 執行

1. 解壓縮 ZIP，開啟 `taipei101_fireworks_v2` 資料夾。
2. 雙擊 `start_windows.bat`，或在 VS Code 終端機依序輸入：

```powershell
python -m pip install -r requirements.txt
python server.py
```

3. 瀏覽器開啟 http://127.0.0.1:7860 。如果先前 Gradio 版仍在執行，先在舊終端機按 Ctrl+C，避免連接埠衝突。

需要 Python 3.10+。Leaflet 與 Three.js 透過 CDN 載入，地圖底圖也需要網路。示範模式的計算不需要 OSM API。

## 使用

- 點擊 2D 地圖上任一視野格子，即更新右側觀測者高度約 1.6 m 的第一人稱 3D 視角。
- 3D 可拖曳環顧四周、滾輪縮放、重設朝向台北101。
- 切換 OSM 真實建物模式會從 Overpass 嘗試取得建物輪廓與 `height` 或 `building:levels`，後者乘以 3 m 為粗略推估。未知高度以 15 m 的**視覺佔位模型**顯示，**不參與作為確定遮擋高度的判定**。
- 推薦目前為規則式，並非真正 LLM；示範模式的人潮及步行時間都是合成值。

## 資料限制

- 101 建物模型是簡化長方體；不是 Google Earth 或精確的台北101外觀。
- 10 個煙火目標高度僅供模擬，未經官方施放位置查證。
- 視野計算假設地面平坦，且缺漏建物高度會導致不確定結果。
- OSM 模式的人潮及步行時間不提供，不能把未知資訊當成符合需求。
- 本專案尚不適用於真實跨年行程決策。
